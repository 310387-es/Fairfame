Revira — how it works

Account model · user flows · roles · multi-location & agency · provisional name

1The Account Model

One mental model for the whole app. Everything belongs to a Location; Locations belong to an Organization; a Team works across them with roles. Reviews roll up from Location → Organization.

3How It's Used — Daily & Weekly Loops

Two rhythms. The daily loop keeps reputation clean; the weekly Action Digest is the habit + the moat.

4Team Access & Roles

Roles are set per Organization; visibility can be scoped to specific locations.

RoleSeesCan doLocation scope
OwnerEverythingFull control incl. billing, delete orgAll
AdminEverythingManage sources, team, settings, replyAll or assigned
MemberAssigned locationsView, reply (draft-only or post), tag, assignAssigned only
ClientOwn locations onlyView reports, limited reply (agency use)Their locations
